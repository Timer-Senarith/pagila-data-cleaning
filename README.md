# Pagila Data Cleaning and Transformation

SQL practice using the Pagila sample database in PostgreSQL.

## Topics covered

- Price classification with CASE WHEN
- Conditional aggregation with COUNT and AVG
- Missing values and safe division with COALESCE and NULLIF
- Row-level limits with GREATEST and LEAST
- Text standardization and type casting
- Monthly payment summaries and rental date analysis
- Review and correction of SQL query logic

## Tools

PostgreSQL 16, Neon, and DBeaver.

## Running the script

Connect to a PostgreSQL database containing the Pagila sample dataset,
open Lab6.sql in DBeaver, and execute the queries.

The script contains SELECT queries and does not modify the source tables.
